Bài 17 — SSE & FPU

Status todoTags step, cpu, fpu

Hàm: initiateSSE() · Spec: Intel SDM Vol.1/Vol.3

Mục đích

Bật đơn vị tính dấu phẩy động / vector (SSE/FPU) để code dùng float/SIMD chạy được mà không fault. Mặc định long mode chưa bật; phải set CR0/CR4. Và phải lưu/khôi phục trạng thái FPU khi đổi task (Bài 12 - Multitasking & Scheduler) — bắt buộc trước khi chạy userspace dùng float (Bài 18 - Userspace & ELF Loader).

Mục tiêu học

  • Bật SSE: CR0 (clear EM, set MP), CR4 (OSFXSR, OSXMMEXCPT).
  • (Tùy) AVX qua XCR0/XSAVE.
  • Lưu/khôi phục trạng thái FPU/SSE khi context switch (fxsave/fxrstor).

Câu hỏi mở

  • [ ] Lazy FP save hay eager?
  • [ ] XSAVE area kích thước (CPUID)?

Ánh xạ spec

  • Intel SDM Vol.1 — SSE/AVX; Vol.3 — control register, XSAVE.
