Bài 18 — Userspace & ELF Loader

Status todoTags step, userspace, elf

Files: entry/* (elf loader), multitasking/* · Spec: ELF64; x86-64 psABI; musl

Mục đích

Chạy chương trình của người dùng ở ring 3 — đích đến của cả hành trình. Đọc file ELF từ đĩa (Bài 15 - AHCI & Filesystems), map các segment vào address space user (Bài 6 - Virtual Memory & Paging), dựng stack + argv/auxv, rồi nhảy xuống ring 3. Gom mọi thứ trước đó: paging (không gian riêng), GDT user segment (Bài 7 - GDT & TSS), syscall (Bài 16 - Fast Syscalls), scheduler (Bài 12 - Multitasking & Scheduler). Kết quả: _start kết thúc bằng run("/bin/bash") — một shell thật chạy trên cavOS.

  • _start kết thúc bằng while(1) run("/bin/bash", ...).
  • ELF loader: đọc file (Bài 15 - AHCI & Filesystems), map các PT_LOAD vào không gian ảo (Bài 6 - Virtual Memory & Paging), dựng stack + auxv, nhảy vào ring 3.
  • Dynamic linking: musl ld.so cho shared library.

✓ Câu hỏi

  • auxv là gì, chứa entry nào (AT_PHDR, AT_ENTRY, AT_RANDOM...)?
  • Chuyển vào ring 3 dùng iret/sysret thế nào? Stack ban đầu layout ra sao (argc/argv/envp/auxv)?
