Limine hay tự viết loader UEFI

Tags concept, boot, uefi, limine

Một kernel có hai lựa chọn trên máy UEFI: dùng một bootloader có sẵn (vd Limine, khai báo các request rồi để nó làm phần việc với firmware), hoặc tự viết một loader UEFI. Trang này liệt kê phần việc đó, tức những gì kernel phải tự làm nếu chọn cách thứ hai.

Hai đường từ firmware tới kernel

Firmware UEFI chỉ chạy một file .efi; file đó là Limine, hoặc là chương trình của chính bạn.

Firmware UEFI chỉ chạy một file .efi trên ESP. Với kernel dùng Limine, file đó là BOOTX64.EFI của Limine. Với một loader tự viết (ví dụ bằng gnu-efi hoặc EDK II), file đó là chương trình của bạn.

Ai làm việc gì

Mỗi thứ kernel cần lúc boot, ai lo trong từng cách.

Cột phải là request của Limine lo việc đó. Cột giữa là việc tương ứng khi tự viết loader.

Tự viết thì học thêm được gì

Tự viết loader là học đúng những thứ Limine đang giấu đi.

Đúng những thứ Limine giấu đi: ESP và đường dẫn boot, Boot Services và Runtime Services, memory map gốc của UEFI và vòng thử lại ExitBootServices, PE và quy ước gọi hàm của firmware, Secure Boot. Đổi lại, mọi thứ Limine làm sẵn (higher-half, HHDM, SMP, boot BIOS) phải tự làm.

Bẫy chung của cả hai cách

Dữ liệu bootloader để lại (response của Limine, page table tạm, stack lúc vào) nằm trong vùng BOOTLOADER_RECLAIMABLE; với loader tự viết là EfiBootServicesData / EfiLoaderData. Đọc xong và đổi CR3 sang bảng của kernel rồi mới đưa vùng đó cho PMM.
