Khái niệm (tra cứu)

Thứ dùng đi dùng lại ở nhiều bài, viết chung cho mọi kernel x86-64; cuối mỗi trang có link tới chỗ cavOS dùng nó.

  • Paging — nền tảng nhất, đọc trước
  • Long Mode — chế độ 64-bit, nơi kernel thực sự chạy
  • Real Mode và Protected Mode — bootloader BIOS, A20, vào protected mode, kernel Multiboot, trampoline CPU phụ
  • Higher-Half Kernel — vì sao kernel nằm ở nửa cao không gian ảo
  • HHDM — cửa sổ nhìn toàn bộ RAM vật lý, và chuyện hai địa chỉ ảo trỏ một chỗ
  • Cấu trúc os.img — ảnh đĩa boot: MBR + FAT32 + Limine, hai đường BIOS/UEFI
  • Boot Protocol & Limine · Request-Response Mechanism — cách kernel hỏi bootloader
  • KASLR & PIE Kernel — kernel chạy được ở địa chỉ nào cũng được, và đặt ngẫu nhiên mỗi lần boot
  • x86 Segmentation — segment + 3 chế độ (real/protected/long)
  • GDT — bảng segment descriptor, selector, TSS, CPL/DPL/RPL
  • ESP và UEFI boot — GPT và ESP, BootOrder, đường dẫn dự phòng, một bootloader đọc kernel thế nào
  • UEFI Runtime Services và biến — Boot và Runtime Services, ExitBootServices, biến UEFI, kernel có cần gọi firmware không
  • Secure Boot — PK/KEK/db/dbx, firmware kiểm chữ ký, shim và MOK, measured boot
  • PE, ELF và quy ước gọi hàm — ứng dụng UEFI là PE32+, kernel là ELF; Microsoft x64 vs System V, vì sao -mno-red-zone
  • Limine hay tự viết loader UEFI — mỗi việc Limine làm hộ, nếu tự viết loader UEFI thì phải làm thế nào
