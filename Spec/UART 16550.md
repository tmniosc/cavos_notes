# UART 16550

> Chip giao tiếp serial. cavOS dùng cho debug qua COM1. Datasheet: **PC16550D** (National/TI).
> Dùng ở [[Step 01 - Serial UART]]. Port COM1 = `0x3F8`, COM2 = `0x2F8`.

## Bản đồ thanh ghi (offset so với base)
| Off | DLAB=0 | DLAB=1 | Ghi chú |
|---|---|---|---|
| +0 | THR(ghi)/RBR(đọc) | DLL | dữ liệu / divisor low |
| +1 | IER | DLM | interrupt enable / divisor high |
| +2 | IIR(đọc)/**FCR**(ghi) | | FIFO control |
| +3 | **LCR** | | line control, bit7 = DLAB |
| +4 | **MCR** | | modem control |
| +5 | **LSR** | | line status |

## Bit quan trọng
- **LCR.DLAB (bit7)**: =1 để truy cập divisor latch (DLL/DLM), =0 để dùng dữ liệu/IER.
- **LSR bit0** = Data Ready (có byte để đọc).
- **LSR bit5 (0x20)** = THR Empty (gửi được byte mới).
- **MCR**: DTR, RTS, **OUT2** (OUT2 cho phép IRQ UART tới PIC/APIC).

## Baud
Clock 1.8432 MHz / 16 = 115200 max. `baud = 115200 / divisor`.
divisor = 3 → 38400 (cấu hình cavOS). **8N1** = 8 data, no parity, 1 stop.

→ Giải mã `serial_enable()` từng dòng: xem [[Step 01 - Serial UART]].
